# Sonic 애니메이션 뷰어 요구사항 정의서

## 1. 목적 및 근거

`PRE-PRD.md`를 바탕으로 `sonic-sprite.png`에 포함된 모든 캐릭터 동작을 자동으로 순환 재생하는 뷰어를 개발한다. Python과 pico2d로 스프라이트 프레임 출력, 반복 재생, 동작 전환을 구현하고 작은 단계의 개발 이력을 남긴다.

초안의 필수 조건과 사용자가 지정한 창 크기(1200 × 800 픽셀)를 적용한다. 이 문서에서 추가한 재생 속도와 정렬 방식은 구현을 위한 기본 제안이며 필요하면 문서를 수정한 뒤 적용한다. 사용자의 추가 요청에 따라 이동 동작의 위치 변화와 애니메이션을 동시에 처리한다.

## 2. 개발 환경 및 산출물

| 항목               | 요구사항                                 |
| ------------------ | ---------------------------------------- |
| 언어 및 라이브러리 | Python 3, pico2d                         |
| 작업 위치          | `Labs/LEC09`                           |
| 작업 브랜치        | `lec09-animation-viewer`               |
| 실행 코드          | `sonic_animation_viewer.py` 단일 파일  |
| 이미지             | 같은 폴더의`sonic-sprite.png`          |
| 문서               | `PRE-PRD.md`, `PRD.md`               |
| 창 크기            | 1200 × 800 픽셀 (사용자 지정)           |
| 프레임 재생 속도   | 기본 제안: 초당 10프레임, 프레임당 0.1초 |

프레임 데이터, 재생 상태, 입력 처리와 화면 출력 코드는 모두 실행 파일 하나에 둔다. 이미지 경로는 실행 파일 위치를 기준으로 계산하여 실행하는 터미널의 현재 폴더가 달라도 이미지를 불러올 수 있게 한다.

## 3. 사용자 시나리오

1. 사용자가 `sonic_animation_viewer.py`를 실행한다.
2. 창이 열리고 첫 번째 동작이 원본 프레임 크기의 4배로 표시된다.
3. 해당 동작의 전체 프레임을 순서대로 5회 재생하며, 이동 동작은 화면 위치도 함께 바뀐다.
4. 다섯 번째 재생의 마지막 프레임과 마지막 위치를 유지한 채 1초 동안 정지한다.
5. 다음 동작의 첫 프레임부터 같은 과정을 수행한다.
6. 마지막 동작도 5회 재생하고 1초 정지한 뒤 첫 동작으로 돌아간다.
7. 사용자가 Esc 또는 창 닫기 버튼을 누를 때까지 전체 순환을 반복한다.

## 4. 기능 요구사항

### FR-01. 스프라이트와 동작 데이터

- 이미지 안의 모든 캐릭터 애니메이션을 등록한다.
- 제목, 제작자 표기, 하단의 장식 이미지는 재생 대상에서 제외한다.
- 기본 재생 순서는 이미지 위쪽부터 아래쪽, 각 동작 내에서는 왼쪽부터 오른쪽으로 한다.
- 이미지의 행과 동작 구분을 먼저 확인하고, 동작별 이름·프레임 수·좌표를 코드에 명시한다. 행 하나가 항상 동작 하나라고 가정하지 않는다.
- 각 프레임은 잘라낼 사각형 `(x, y, width, height)`으로 정의한다. 불규칙한 간격이나 크기를 고정 격자로 추측하지 않는다.
- 이미지 왼쪽 위 기준으로 측정한 좌표는 pico2d의 왼쪽 아래 기준으로 변환한다. 이미지 높이가 `H`, 프레임 위쪽 좌표가 `top`, 높이가 `h`이면 `y = H - top - h`이다.
- 모든 좌표가 이미지 경계 안에 있고, 캐릭터가 잘리거나 옆 프레임이 섞이지 않는지 확인한다.

### FR-02. 화면 출력

- 각 프레임의 원본 너비와 높이에 각각 4를 곱하여 출력한다. 가로세로 비율을 유지한다.
- 동작 시작 시 창 중앙에서 시작한다. 이동 동작은 위치를 갱신하고, 회전 진입과 포즈는 중앙에 고정한다. 매 프레임 배경을 지운 뒤 현재 위치에 그린다.
- 가장 큰 프레임도 4배 크기에서 1200 × 800 픽셀 창 밖으로 잘리지 않아야 한다.
- 배경은 캐릭터를 구분하기 쉬운 단색으로 한다.

### FR-03. 동작별 5회 반복

- 한 동작의 첫 프레임부터 마지막 프레임까지 표시한 것을 1회로 센다.
- 정확히 5회를 완료한 뒤 정지 상태로 전환한다.
- 동작이 바뀔 때 프레임 번호와 반복 횟수를 초기화한다.
- 프레임 속도는 상수로 관리하며, 기본값은 프레임당 0.1초로 한다.

### FR-04. 1초 정지 및 다음 동작 전환

- 다섯 번째 반복의 마지막 프레임도 정상 표시 시간 동안 보여 준 뒤, 추가로 1초 동안 유지한다.
- 정지 중에는 프레임과 표시 위치가 바뀌지 않는다.
- 정지 시간은 경과 시간으로 측정한다. 1초가 지난 후 다음 동작으로 전환한다.
- 정지 중에도 종료 입력을 처리한다.

### FR-05. 전체 무한 순환

- 등록된 모든 동작을 정해진 순서로 재생한다.
- 마지막 동작의 정지가 끝나면 첫 동작의 첫 프레임으로 돌아간다.
- 순환이 반복되어도 프레임 번호나 반복 횟수가 누적되어 재생이 생략되지 않아야 한다.

### FR-06. 종료 및 오류 처리

- 재생 중과 정지 중 모두 Esc와 창 닫기 버튼으로 종료할 수 있어야 한다.
- 긴 대기로 입력 처리가 막히지 않도록 한다.
- 종료 시 캔버스를 닫는다.
- 이미지가 없거나 불러오기에 실패하면 필요한 파일명과 경로를 확인할 수 있는 오류 메시지를 출력한다.

### FR-07. 동작별 이동과 화면 경계

이동 속도는 초당 픽셀 단위이며 프레임 전환과 별도로 매 루프의 경과 시간에 곱해 적용한다. 아래 값은 기본 구현값이다. 원본 4배 크기는 이동 방향이나 위치와 관계없이 유지한다.

| 동작 | 이동 방식 | 초기 속도 (vx, vy) |
| --- | --- | --- |
| 걷기 및 회전 진입 | 수평 걷기 | (120, 0) |
| 달리기 | 수평 달리기 | (240, 0) |
| 질주 | 수평 질주 | (360, 0) |
| 회전 | 중앙에서 회전 준비, 위치 고정 | (0, 0) |
| 고속 회전 | 수평 구르기 | (320, 0) |
| 대각선 달리기 | 오른쪽 위 대각선 이동 | (180, 100) |
| 대각선 질주 | 오른쪽 위 대각선 이동 | (280, 160) |
| 공중 회전 | 수평 이동과 반복 점프 | (200, 0), 점프 높이 160 |
| 정면 달리기 | 화면 아래쪽으로 이동 | (0, -180) |
| 포즈 | 중앙 고정 | (0, 0) |

- 각 동작의 가장 큰 프레임의 4배 크기를 기준으로 가장자리에 20픽셀 여백을 둔다.
- 수평·수직 경계에 닿으면 해당 축의 진행 방향을 반전하고, 넘친 이동 거리도 안쪽으로 반영한다.
- 수평 이동은 왼쪽으로 향할 때 프레임을 좌우 반전한다. 수직 이동은 이미지를 뒤집지 않는다.
- 점프 높이는 `160 × sin(π × 점프 진행률)`로 계산한다. 한 동작의 프레임 1회 재생마다 한 번 점프하며, 진행률은 현재 프레임 번호와 그 프레임의 경과 시간으로 계산한다.
- 같은 동작을 반복할 때 수평 위치는 이어진다. 다음 동작으로 전환할 때 위치를 중앙으로, 속도와 방향을 해당 동작의 초기값으로 되돌린다.
- 5회 완료 후 1초 정지 중에는 위치·방향·프레임을 모두 유지한다. 정지 시간은 다음 이동량에 합산하지 않는다.

## 5. 구현 구조 제안

단일 파일 안에서 상수, 동작별 프레임 데이터, 이미지 로딩, 이벤트 처리, 화면 그리기, 재생 상태 갱신을 구분한다.

재생 상태에는 현재 동작 번호, 프레임 번호, 완료한 반복 횟수, 재생/정지 상태와 시간 기준값, 위치, 속도, 이동 방향과 점프 경과 시간을 둔다. 기본 흐름은 다음과 같다.

```text
초기화 → 첫 동작 재생
재생 → 전체 프레임 1회 완료 → 5회 미만이면 같은 동작 반복
5회 완료 → 마지막 프레임 유지하며 1초 정지
정지 완료 → 다음 동작 재생
마지막 동작의 정지 완료 → 첫 동작 재생
어느 상태에서든 종료 입력 → 종료
```

## 8. 구현 전 확정할 데이터 및 범위

- 스프라이트를 직접 대조하여 동작별 프레임 수와 좌표를 확정한다. 실습 자료의 예시 수치를 검증 없이 그대로 사용하지 않는다.
- 현재 범위는 이동·점프와 애니메이션의 동시 자동 재생이다. 키 입력을 통한 동작 선택은 포함하지 않는다.
- 이동 기능은 단계별로 구현하고 로컬 커밋을 남긴다. 이번 수정의 실행 검증은 사용자가 담당하며 GitHub 업로드는 수행하지 않는다.
